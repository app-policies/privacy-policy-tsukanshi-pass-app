# 通関士Pass プライバシーポリシー

最終更新日: 2026年7月26日

通関士Pass（以下「本アプリ」）は、学習機能、広告表示、アプリ内課金、利用状況の分析のために、端末上の学習履歴および外部サービスが提供する識別子等を利用する場合があります。

本アプリは、ログインやアカウント作成を必要としません。

## 収集する情報

- 学習履歴、回答履歴、正誤履歴、苦手問題、連続学習日数など、アプリ内で保存される学習データ
- アプリの設定情報
- 広告配信や広告効果測定に必要な識別子
- アプリ内課金の購入状態を管理するために必要な情報
- アプリの起動、学習開始、回答、学習完了、模試完了、課金画面表示など、利用状況の把握に必要なイベント情報
- クラッシュ、不具合、利用状況の把握に必要な技術情報

本アプリは、氏名、住所、電話番号、メールアドレス、連絡先、正確な位置情報を、アカウント情報として独自に取得しません。

## 利用目的

- 問題演習、復習、学習進捗表示の提供
- 誤答優先学習、苦手問題、連続学習日数などの学習機能の提供
- 広告表示
- アプリ内課金の購入状態の確認、復元、管理
- 利用状況の分析、機能改善、学習体験の改善
- 不具合調査、品質改善、クラッシュ解析

## 学習データの保存

学習履歴、回答履歴、苦手問題、連続学習日数などの学習データは、原則として利用者の端末内に保存されます。

本アプリは、学習履歴を管理するための独自アカウントサーバーを運営していません。端末の削除、アプリの削除、端末変更などにより、端末内の学習データが失われる場合があります。

## 広告について

本アプリでは、Google Mobile Ads を利用して、バナー広告、インタースティシャル広告、リワード広告を表示する場合があります。

リワード広告では、広告視聴後に一部の追加問題を解放する場合があります。解放された問題の利用権は端末内に保存され、翌日以降も継続して利用できます。広告の在庫状況、通信状態、端末環境などにより広告を表示できない場合があります。

Google Mobile Ads では、広告配信、広告効果測定、不正防止などのために、端末情報、広告識別子、利用状況に関する情報が利用される場合があります。これらの情報の取り扱いは、Google のポリシーに従って管理されます。

## アプリ内課金について

本アプリでは、非消耗型のアプリ内課金により、全問題の利用、広告非表示、詳細解説、選択肢ごとの解説、苦手問題モードなどの機能を提供する場合があります。

購入処理は Apple App Store または Google Play の仕組みを通じて行われ、購入状態の管理には RevenueCat を利用します。RevenueCat では、購入状態の確認、復元、課金機能の提供に必要な識別子や購入情報が取り扱われる場合があります。

## Firebase Analytics について

本アプリでは、アプリの利用状況を把握し、学習体験や機能改善に役立てるために Firebase Analytics を利用します。

Firebase Analytics では、アプリの起動、学習モードの利用、分野ID、回答の正誤、学習完了、模試結果のスコア帯、課金画面の表示元、購入フロー、レビュー依頼候補などのイベント情報を送信する場合があります。

Firebase Analytics には、問題本文、選択肢本文、解説本文、自由入力、記述答案、氏名、メールアドレス、個別相談内容、各ストアの決済識別子の生値、広告IDを送信しません。

本アプリでは、Firebase Auth、Firestore、Realtime Database、Cloud Functions、Storage、Remote Config、Crashlytics を利用していません。

Firebase および Google による情報の取り扱いについては、以下をご確認ください。

- Google プライバシーポリシー: https://policies.google.com/privacy
- Firebase のプライバシーとセキュリティ: https://firebase.google.com/support/privacy

## 第三者サービス

本アプリでは、広告配信、課金管理、品質改善のために、以下の第三者サービスを利用する場合があります。各サービスで取り扱われる情報は、それぞれのプライバシーポリシーに従って管理されます。

- Google Mobile Ads
- Firebase Analytics
- RevenueCat
- Apple が提供する App Store、アプリ内課金、クラッシュログ、診断関連サービス
- Google が提供する Google Play、アプリ内課金、クラッシュログ、診断関連サービス

## 外部送信

広告配信、課金管理、利用状況の分析、クラッシュ解析、品質改善のため、第三者サービスに端末情報、広告識別子、購入情報、利用状況イベント、クラッシュ情報、診断情報などが送信される場合があります。

本アプリは、利用者が入力した氏名、住所、電話番号、メールアドレス、連絡先、正確な位置情報を独自に収集して外部送信する機能を持ちません。

本アプリは、問題本文、選択肢本文、解説本文、自由入力、記述答案、氏名、メールアドレス、個別相談内容、各ストアの決済識別子の生値、広告IDを Firebase Analytics に送信しません。
